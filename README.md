# দোয়েল — Performance & Streetwear

A single-page sportswear storefront. Customers browse products and place orders through the WhatsApp button (there is no online checkout).

## Files
- `index.html` — page structure and content
- `styles.css` — styling, responsive for phone and desktop
- `script.js` — shopping bag, search, filters and mobile menu
- `doel-bird-logo.jpg` — brand logo

## View locally
Double-click `index.html` to open it in any browser.
